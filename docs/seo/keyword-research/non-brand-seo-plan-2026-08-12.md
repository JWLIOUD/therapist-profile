## 為何選這個方案

### 過去研究證據

1. `keyword-opportunity-2026-07-25.md` 將「職場霸凌防治新制／職場心理健康」列為第一順位，機會分數 90；研究限制已明確標示沒有精確搜尋量。
2. `team-analysis-2026-07-25.md` 將「職場霸凌怎麼辦／心理影響／自我保護」列為第一順位查詢群，研究品質通過、信心中。
3. `seo-directions-2026-07-25.md` 與三方案評估均指出，`workplace-05` 最明確的問題是 description 使用被截斷的故事片段，單頁精修是最低風險方向。
4. 2026-08-12 Search Console 顯示流量仍以品牌詞為主，且 `workplace-mental-health.html` 尚未建立索引；因此本案不把廣義「職場心理健康」指定給單篇文章，也不修改導航頁，而是讓已索引的 `workplace-05` 承接更具體的心理支持意圖。

### 目前頁面缺口

- `<title>` 與 H1 已包含「職場霸凌」，但沒有直接對應「怎麼辦」的問題型搜尋情境。
- meta description、OG description、Twitter description、Article JSON-LD description 與頁首可見摘要，都是同一段被省略號截斷的故事開頭，沒有說明讀者能得到什麼。
- 「什麼是黑羊效應？」與「職場中，如果你是黑羊（受害者）」目前是一般段落，不是主要章節標題；後續自我保護步驟則全部平鋪為 H2，資訊層級不夠清楚。
- 文章內容本來就包含自責、界線、支持系統、事件紀錄、旁觀者及團隊安全，不需要為 SEO 增加新的心理或法律主張。

### 當下搜尋意圖邊界

勞動部目前已有「發生職場霸凌怎麼辦？」專區與正式防治手冊，適合承接制度、法規及申訴流程。本站不應與官方頁爭奪法律定義，而應補足「在制度處理之外，如何理解心理反應、保護自己、尋求支持與避免孤立」的意圖。

## 預計修改內容

以下是使用者核准、並由內容與 SEO 團隊套用到本地候選的文字基準。

### 1. 搜尋標題與 H1

建議 `<title>`：

> 職場霸凌怎麼辦？從黑羊效應理解心理影響與自我保護｜黃郁倩諮商心理師

建議 H1：

> 職場霸凌怎麼辦？從黑羊效應理解心理影響與自我保護

同步欄位：`og:title`、`twitter:title`、Article JSON-LD `headline`。

原意保真：保留「黑羊效應」、「職場霸凌」、「保護自己」三個原始主題，只把讀者搜尋問題前置；不宣稱文章能判定霸凌是否成立。

### 2. 摘要

建議 meta description／可見導讀基準：

> 遇到疑似職場霸凌時，為什麼容易自責、孤立或不知所措？本文從黑羊效應整理界線表達、支持系統、事件紀錄與旁觀者可做的事；不取代申訴、法律或醫療判斷。

同步欄位：meta description、OG description、Twitter description、Article JSON-LD `description` 與 `.article-description`。

原意保真：摘要只濃縮正文已有內容與既有內容聲明，不增加新的處理程序、資源資格或效果保證。

### 3. 章節語意層級

核准後只調整標題措辭與 HTML 層級，段落正文逐字保持：

| 目前 | 候選 | 原意保留方式 |
|---|---|---|
| 一般段落「什麼是黑羊效應？」 | H2「什麼是黑羊效應？為什麼可能演變成職場霸凌？」 | 後文原本已說明演變關係，不新增因果 |
| 一般段落「職場中，如果你是黑羊（受害者）」 | H2「遇到職場霸凌時，可以先怎麼保護自己？」 | 只作為既有六個自我保護步驟的父標題 |
| 六個自我保護步驟使用 H2 | 改為 H3，文字保持不變 | 建立父子層級，不改建議內容 |
| H2「職場中，如果你是白羊（旁觀者）」 | H2「如果你是旁觀者，可以如何提供支持？」 | 保留旁觀者責任與支持觀點，避免角色標籤成為搜尋主題 |
| 結尾 H2 | 完全保持 | 保留個人尊嚴、團隊安全與互相支持的結論 |

### 4. 技術一致性

- URL、canonical、robots、sitemap 與發布日期維持不變。
- 不新增 FAQ structured data；目前方案沒有新增獨立 FAQ 內容。
- 圖片、alt、版面、CTA、原刊來源與免責聲明維持不變。
- 不加入 `meta keywords`，不做隱藏文字或關鍵字重複。
- `workplace-mental-health.html` 繼續定位為廣義職場心理健康導航；`workplace-05.html` 只承接具體的職場霸凌心理支持意圖。

## 明確不可修改

- 大黑案例的人物、情節、角色關係、因果與用途。
- 黑羊效應的解釋與原刊引用。
- 常見職場不法侵害類型、求助界線與蒐證安全提醒。
- 不自責、不討好、找支持、表達界線、保留紀錄與守住自我價值的主張。
- 旁觀者不加入排擠、提供關心與支持的觀點。
- 位階不同仍不應遭惡意對待的結論。
- 原刊來源、內容聲明、心理師資格、服務資訊與 CTA。
- 不得新增法律判定、診斷、療效承諾、雇主／HR 必然有責或個案必然正確的說法。

- `positive`：目標 query 群與目標頁出現一致、可重現的非品牌曝光／點擊成長，且未把廣義「職場心理健康」從導航頁錯誤移轉。

- `no_clear_change`：資料量或觀察期不足；不反覆改稿。
- `negative`：足夠樣本下目標頁非品牌表現下降，或明顯造成互搶；優先回復本案單一 commit。

## 風險與回復

- 風險：實際 Search Console 尚未顯示「職場霸凌怎麼辦」query，需求證據主要來自過去研究、政策時效與頁面內容缺口；所以信心只列中。
- 風險：Google 可自行改寫 title link 與 snippet，metadata 修改不保證實際呈現。
- 風險：若標題過度像法律指南，可能吸引錯誤意圖；因此摘要必須明示心理支持定位與不取代正式判斷。
- 回復：所有網站修改限定單一需求 commit；若 28／90 天證據顯示負向，可回復 title、description、可見導讀與 heading 層級，不影響 URL 或正文。
