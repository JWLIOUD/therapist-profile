# 職場心理健康三種 SEO 方案評估

任務 ID：`SEO-INTEL-20260725-02`
狀態：`user_preview`
發布狀態：未發布

## 評估摘要

| 方案 | 主要價值 | 風險 | 工作量 | 建議 |
|---|---|---|---|---|
| A 單篇精修 | 快速改善明確搜尋意圖，原意風險最低 | 廣義覆蓋有限 | 低 | 第一優先 |
| B 職場心理健康總論 | 建立廣義入口，方便導向所有職場主題 | 新頁、互搶、需求量尚未驗證 | 中 | 等第一方數據 |
| C 文章群意圖分層 | 架構最完整，降低互搶並強化內鏈 | 涉及多頁，驗收與歸因成本高 | 高 | 第二階段 |

## 方案 A

### 可參考之處

- 修正現有最明顯的 SEO 問題：description 是截斷故事。
- title、H1、段落標題更貼近「職場霸凌怎麼辦」與心理支持意圖。
- 不需要新增 URL，最容易保留原文與來源。
- 可先建立 Search Console 成效基準，後續容易歸因。

### 問題

- 主要只提升霸凌單篇，無法承接廣義「職場心理健康」。
- FAQ 與制度來源需保持一般說明，不能寫成法律判定。

### 評估

最適合先正式化，但正式版應直接在原文章做小範圍 diff，不使用目前預覽中的摘要占位文字。

## 方案 B

### 可參考之處

- 可以回答「我現在面對的是霸凌、倦怠、PUA、界線還是同情疲勞？」。
- 對第一次進站、還不知道要看哪篇文章的人很友善。
- 能成為職場心理健康的資訊型入口。

### 問題

- `series/workplace.html` 也可能承接廣義主題，需明確區分分類導航與資訊總論。
- 現有 SEO 測試文範圍過寬，不能原樣正式化。
- 缺 Search Console／Trends 數據支持廣義關鍵字需求。
- 新頁需要完整來源、專業審閱、URL、canonical 與 sitemap。

### 評估

目前保留草稿。等 A 發布後 28／90 天或取得 Search Console query 資料，再決定是否建立。

## 方案 C

### 可參考之處

- 每篇文章有清楚主搜尋意圖，最能避免關鍵字互搶。
- 系列頁作 hub，單篇作 spoke，資訊架構清楚。
- 既有文章資產已足夠，不一定需要大量新增內容。
- 可以與 A 分階段共存。

### 問題

- 涉及系列頁與多篇文章的摘要／內鏈，改動面較大。
- 若同批修改多頁，Search Console 成效較難歸因。
- 每個既有頁仍需語意保真與逐頁驗收。

### 評估

適合作為 A 之後的第二階段，先更新系列頁導航，再逐篇補相關閱讀，不一次改完全部頁面。

## 是否可以一起上

三者不是互斥版本，但不建議同一批一起發布。

可分階段併用：

1. A：先精修 `workplace-05`，建立可歸因的第一個變更。
2. C：第二階段整理系列頁與內部連結。
3. B：只有 Search Console／趨勢資料支持廣義查詢時，再新增總論。

如果 A、B、C 同時發布：

- 無法判斷哪個修改帶來成效。
- `series/workplace` 與新總論可能競爭廣義關鍵字。
- 專業與語意驗收工作量同時增加。

## 最終推薦

推薦選擇「A 先上、C 接續、B 等數據」。

目前最合理的下一步是使用者先確認方案 A 的 title、description、H 標題與 FAQ 方向。確認後另開正式需求單，只修改 `articles/workplace-05.html`，完成本地 diff 與語意保真驗收，仍不直接發布。

## 本地驗收證據

- 預覽入口與 A／B／C：HTTP `200`。
- 核心頁：首頁、文章列表、講座頁、原文章與職場系列頁 HTTP `200`。
- 桌面版與 375px 手機版無水平溢位。
- 瀏覽器 console 無 warning／error。
- 四個預覽頁均為 `noindex, nofollow`。
- sitemap、正式導覽、正式文章與 CSS 無修改。
