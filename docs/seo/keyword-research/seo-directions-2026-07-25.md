# SEO 文案與網站修改方向

任務 ID：`SEO-INTEL-20260725-02`

## 共同規則

- 三版都不改正式網站。
- 原文心理意義、案例、結論、來源與服務界線不變。
- 政策資訊只提供官方來源與一般說明，不代替法律判斷。
- 不以關鍵字密度為目標。

## A：單篇低風險精修

目標：讓 `workplace-05` 更清楚承接「職場霸凌怎麼辦／心理影響／自我保護」。

修改方向：

- title／H1 前置職場霸凌，保留黑羊效應。
- description 改為完整效益摘要，不再使用截斷故事。
- 把概念、自助與旁觀者段落整理成查詢式標題。
- FAQ 只重述本文：黑羊效應、先做什麼、心理支持能做什麼。
- 內鏈分流到職業倦怠、職場 PUA、拒絕界線與講座邀約。

問題：改善集中在單頁，無法完整承接「職場心理健康」廣義意圖。

## B：職場心理健康總論

目標：建立廣義資訊入口，再導向每個既有專題。

修改方向：

- 新頁只回答職場心理健康的辨識、影響面向、何時需要支持。
- 每個子題只做短摘要與連結，不複製既有文章。
- 明確區分個人照顧、組織責任與正式制度。

問題：需要新增正式 URL、來源、專業審閱與 sitemap；現階段缺 Search Console 證明廣義詞需求。

## C：職場文章群意圖分層

目標：用系列頁清楚分流霸凌、倦怠、PUA、界線、職家平衡、同情疲勞與新鮮人適應。

修改方向：

- 系列頁標示不同困擾與文章入口。
- 各卡片摘要直接回答讀者會得到什麼。
- 建立 hub ↔ article 與 article ↔ related article 內鏈。
- `talks.html` 只承接講座服務，不搶資訊型查詢。

問題：涉及多頁，驗收成本最高；若沒有 Search Console 基準，同批修改後較難歸因。

## SEO 團隊結論

- A 可立即作為低風險正式候選。
- C 可與 A 分階段搭配，先整理資訊架構，再逐頁補內鏈。
- B 適合在 Search Console／Trends 支持廣義「職場心理健康」需求後正式建立。
- 不建議三版同時一次上線；建議 A → C → B 的分階段順序。
