# SEO 初步檢查

檢查日期：2026-06-19

## 結論

目前本地 SEO 基礎設定大致正常：`robots.txt` 允許抓取，`sitemap.xml` 有列出文章頁，文章頁多數設為 `index, follow`，canonical 也指向正式網址。

但 Google 搜尋目前查不到文章頁，代表文章頁尚未進入公開搜尋結果。這不一定是錯誤；新站或新 sitemap 更新後，5 天仍未收錄文章頁是可能發生的。

追加檢查後，正式站 robots、sitemap、代表文章頁與 Googlebot User-Agent 皆可正常讀取，未發現阻擋索引的技術設定。已先修正首頁內部連結不足的問題，讓首頁直接連到重要文章。

## 目前異常或風險

- Google `site:yuchienpsy.com/articles` 查不到文章結果。
- Google `site:yuchienpsy.com "停不下來不是你的錯"` 查不到結果。
- 單靠更新 sitemap 不保證 Google 會在 5 天內索引所有文章。
- 若 Search Console 沒有提交 sitemap 或沒有要求建立索引，等待時間可能更長。
- 若文章內容與台北市社區心理衛生中心原刊內容高度相似，Google 可能會選擇原站作為主要索引版本，本站文章索引速度或排名可能受影響。
- 首頁原本沒有直接連到文章頁，已於本次修正。

## 建議立即操作

1. 到 Google Search Console 新增並驗證 `https://yuchienpsy.com/`。
2. 提交 sitemap：`https://yuchienpsy.com/sitemap.xml`。
3. 用 URL Inspection 檢查：
   - `https://yuchienpsy.com/articles/addiction-01.html`
   - `https://yuchienpsy.com/articles/workplace-01.html`
   - `https://yuchienpsy.com/articles/boundary-01.html`
4. 對重要文章按「要求建立索引」。
5. 若 Search Console 顯示「已探索但尚未建立索引」或「已檢索但尚未建立索引」，優先加強內部連結與文章摘要獨特性。

## 後續改善

- 文章列表頁加入更清楚的分類與重點文章。

- 確保每篇文章有足夠內部連結，而不只是 sitemap 裡存在。
- 發布新文章後固定執行 Search Console URL Inspection。

## 工具執行注意事項

正式站檢查時，不要使用 `Invoke-WebRequest ... | Select-Object StatusCode,Content` 直接輸出 sitemap 或完整 HTML。這個方式容易在目前環境等待過久或造成大量輸出。

改用狀態碼與內容長度即可：

```powershell
Invoke-WebRequest -Uri https://yuchienpsy.com/sitemap.xml -UseBasicParsing |
  Select-Object StatusCode,@{Name='Length';Expression={$_.Content.Length}}
```
