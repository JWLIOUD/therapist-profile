## 使用者目標

讓「職場心理健康指南」成為正式網站導覽的一部分，並提供 Google 可理解、可爬取且不依賴關鍵字堆砌的搜尋發現訊號。

## 現況核對

- `sitemap.xml` 已有且只有一筆 `https://yuchienpsy.com/workplace-mental-health.html`。
- `robots.txt` 已宣告 `Sitemap: https://yuchienpsy.com/sitemap.xml`。
- 指南維持 `index, follow`、正確 canonical、WebPage、BreadcrumbList 與七篇職場文章 ItemList。
- 全站 34 個正式頁首均有標準 `<a href>` 的桌機「心理專欄 → 職場心理健康」下拉入口。
- 全站 34 個正式頁首均有同一目的地的手機子項。
- 首頁與文章列表另有具上下文的內容型內部連結，不只依賴隱藏式下拉。

## 本次在範圍內

- 保留 sitemap 中單一正式指南 URL，不建立重複 URL。
- 因 34 個正式頁均修改導覽連結，將 sitemap 的 34 個 `<lastmod>` 更新為 `2026-07-30`。
- 指南已有 1600 × 900、16:9、非文字型專屬插畫；robots 保留 `index, follow` 並加入 `max-image-preview:large`，允許 Google 在 Search／Discover 使用大型圖片預覽。
- 驗證 sitemap XML、URL 唯一性、正式頁檔案存在、草稿未混入。
- 五重驗收需確認文案原意、視覺、架構、SEO 與組織合作視角均未被破壞。
- 發布後依 Search Console 工作流檢查 sitemap 與指南 URL；若已要求建立索引、處理中或已收錄，不得重複送出。

## 不在範圍內

- 新增 `meta keywords`；Google Search 不使用此標籤做索引或排名。
- 為了 SEO 改寫指南、文章或講座正文。
- 在頁首、頁尾或正文重複堆疊同一關鍵字連結。
- 宣稱 sitemap、結構化資料或 Request Indexing 可保證收錄、排名或「推播」。
- 在本地候選尚未發布前操作 Search Console Request Indexing。
- 未經使用者核准 commit、push、PR、合併或部署。

- 每個 sitemap URL 都能對應 repo 內正式頁；首頁 `/` 對應 `index.html`。
- sitemap 不含 `drafts/`、`docs/drafts/` 或 `noindex` 相容轉址頁。
- canonical、JSON-LD、正文與草稿邊界保持不變。
- robots meta 恰為 `index, follow, max-image-preview:large`，沒有加入阻擋索引或限制圖片預覽的規則。

## 官方依據

- Google Search Central：可爬取連結與清楚 anchor 可協助 Google 發現並理解頁面。
- Google Search Central：桌機與手機應提供一致的重要連結。
- Google Search Central：sitemap 用來告知重要或已更新頁面，但不保證爬取、收錄或排名。
- Google Search Central：`lastmod` 應反映主內容、結構化資料或頁面連結等重大更新。
- Google Search Central：Discover 內容需先被索引並符合內容政策；大型圖片建議至少 1200px、16:9，並以 `max-image-preview:large` 開放大型預覽，但仍不保證出現在 Discover。
