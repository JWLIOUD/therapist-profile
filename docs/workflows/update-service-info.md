# 固定流程：修改服務資訊

負責角色：網站總管 AI、內容編輯 AI、前端維護 AI、品牌素材 AI、品質檢查 AI

## 觸發條件

你要修改諮商服務、講座邀約、預約方式、LINE 連結、QR code、服務對象、服務地點或費用資訊時啟動。

## 流程

1. 網站總管 AI 先確認新版資訊與舊版差異。
2. 內容編輯 AI 檢查文案是否清楚、專業、沒有過度承諾。
3. 前端維護 AI 修改相關頁面：
   - `index.html`
   - `talks.html`
   - 其他有 CTA 或服務資訊的頁面
4. 品牌素材 AI 檢查：
   - LINE URL
   - QR code
   - 頭像或品牌圖
   - CTA 文字一致性
5. SEO / 發布維護 AI 檢查首頁 meta description 是否需要同步調整。
6. 品質檢查 AI 做桌面與手機版檢查。
7. 網站總管 AI 回報改動與待你確認事項。

## 必填資料

- 要修改的服務項目
- 新版文字
- 是否立即上線
- 是否涉及價格、地點、資格、預約方式或法規敏感資訊

## 完成標準

- 全站 CTA 指向一致。
- 手機版按鈕與聯絡區塊可讀、可點。
- 首頁與服務頁沒有互相矛盾的資訊。
- 若服務定位大幅改變，首頁 meta description 已同步更新。
