# 工作流：修改服務、預約與 CTA 資訊

更新日期：2026-07-25

## 觸發與負責角色

- 觸發：修改諮商服務、講座邀約、預約方式、LINE、Email、QR code、服務對象、地點、費用或資格資訊。
- 統籌：網站總管 AI。
- 執行：內容編輯 AI、前端維護 AI、品牌素材 AI、SEO／發布維護 AI。
- 審查：品質檢查 AI；所有事實由使用者確認。

## 必要輸入與阻擋條件

必須取得新版文字、適用日期、受影響服務及是否立即上線。

費用、地點、資格、聯絡方式、服務範圍或法規資訊未由使用者確認時，不得自行推測或發布。

## 總管需求單

- 列出舊版與新版差異。
- 盤點所有重複出現的頁面、CTA、structured data、QR code 與 metadata。
- 指定內容、前端、品牌、SEO 與 QA 的交付。
- 明列不可改變的服務界線與使用者預覽點。

## 執行與交接

1. 內容編輯 AI 檢查新版資訊清楚、專業且無療效承諾。
2. 前端維護 AI 更新所有受影響頁面與 CTA。
3. 品牌素材 AI 核對 LINE URL、QR code、Email、圖像與 CTA 一致。
4. SEO／發布維護 AI 檢查首頁／服務頁 description、structured data 與索引設定。
5. 品質檢查 AI 做全站文字搜尋、桌面／手機、CTA 實際操作及舊資料殘留檢查。
6. 總管交使用者預覽；核准後才可發布。

## 驗收

- 首頁、`talks.html`、導覽、頁尾及所有 CTA 沒有互相矛盾。
- LINE、Gmail、複製 Email 與 QR code 至少有可驗證的有效路徑。
- 手機按鈕可讀、可點、不遮擋。
- metadata 與頁面可見文字一致。
- 舊費用、地點、服務或聯絡資訊已全部移除或保留理由清楚。
- 完整 `pre-publish-check.md` 通過。

## 完成與停止條件

- 完成：使用者確認事實與預覽，發布及正式站 CTA 驗證完成。
- 停止：新版資訊相互衝突、無法驗證、可能涉及未確認法規／資格或會改變服務承諾。
