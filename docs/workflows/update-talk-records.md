# 工作流：更新講座紀錄與講座邀約頁

負責角色：網站總管 AI、內容文案 AI、SEO / 發布維護 AI、前端與風格圖 AI、品質檢查 AI

## 觸發條件

- 新增或修改 `講座紀錄.csv`。
- 新增重要合作單位、講座主題或系列課程。
- 想提升 `心理師講座邀約`、`職場心理健康講座`、`親職講座` 等搜尋流量。

## 操作流程

1. 讀取 `講座紀錄.csv`
   - 確認日期、合作單位與講座主題。
   - 不將內部行政欄位放入公開頁。

2. 內容整理
   - 將紀錄整理成主題群，而不是逐筆照貼。
   - 不放合作紀錄表格。
   - 不用數字摘要作為主要宣傳內容，避免讓讀者誤解合作範圍受限。
   - 合作單位以場域分類字卡呈現；社區心理衛生中心歸入公部門與社區心理衛生相關場域。
   - 優先呈現行政人員會用來判斷合作的資訊：
     - 可邀約主題
     - 適合單位
     - 合作形式
     - 來信需要提供的資訊

3. SEO 檢查
   - `talks.html` title 包含 `心理師講座邀約`。
   - description 清楚說明合作場域與主題。
   - canonical 指向 `https://yuchienpsy.com/talks.html`。
   - robots 為 `index, follow`。
   - sitemap 包含 `https://yuchienpsy.com/talks.html`。

4. 前端檢查
   - 主題卡可快速掃描。
   - 首頁與文章頁導覽都能到 `talks.html`。
   - 合作單位字卡在手機版與桌機版都能自然換行，不擠壓破版。
   - Gmail 邀約按鈕需直接開啟 Gmail 撰寫頁。
   - 若 Gmail 被瀏覽器阻擋，需至少複製 Email 並顯示提示。
   - 複製 Email 按鈕需能複製 `yuchien9489@gmail.com`。

5. 發布前與發布後驗收
   - 本機確認 `talks.html` 回 `200` 且有內容。
   - 正式站確認 `https://yuchienpsy.com/talks.html` 回 `200` 且有內容。
   - 全站連結檢查通過後再進 Search Console。

## 完成標準

- 行政人員可以在 30 秒內理解可邀約主題。
- 潛在個案看見合作紀錄時，能感受到心理師有穩定的專業經驗。
- 搜尋引擎能把 `talks.html` 視為獨立可索引頁。
- Gmail / Email CTA 在桌機與手機都能完成「開啟 Gmail 或複製 Email」其中一個有效動作。
