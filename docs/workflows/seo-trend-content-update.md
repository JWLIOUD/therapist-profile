# 工作流：趨勢情報驅動的 SEO 內容更新

更新日期：2026-07-25

## 觸發與負責角色

- 觸發：心理健康搜尋情報已通過研究品質檢查，且建議更新既有頁面。
- 統籌：網站總管 AI。
- 執行：內容編輯 AI、SEO／發布維護 AI；需要版面時加入前端維護 AI與品牌素材 AI，缺少合適插畫時再加入插畫設計 AI。
- 審查：品質檢查 AI。
- 核准：使用者。

## 不可妥協原則

- 只處理與心理健康及網站專業直接相關的需求。
- SEO 更新不是內容重寫；原文意義優先於關鍵字。
- 不改變核心觀點、心理概念、案例意義、角色關係、專業主張、結論、服務界線、來源與作者歸屬。
- 不增加診斷、恐嚇、療效承諾、法律／制度定論或事件借勢。
- 無法在保留原意下完成時，停止並改提新增文章或持續觀察。
- 使用者預覽前不得發布，不得直接推送 `main`。

## SEO 可修改範圍

- title、meta description、OG、Article JSON-LD 描述欄位。
- H1／H2／H3 措辭與層級，但段落主張不變。
- 導言中的搜尋情境提示與原文摘要。
- 自然同義詞、FAQ、目錄、延伸閱讀與內部連結。
- 圖片 alt、canonical、更新日期與結構化資料。
- 有一手來源與日期的背景說明框；不得扭曲原文。

## 總管需求單

必填：

- 來源情報報告、證據、信心與資料限制。
- 目標 URL、讀者、搜尋意圖、主／次關鍵字與時效。
- 現行 SEO 問題與預期修正。
- SEO 可改欄位與不在範圍內項目。
- 原文語意基準與禁止改動清單。
- 各角色交付、預覽、驗收、發布與成效指標。
- 發布後 Search Console 的 7／28／90 天檢查時間、目標 query cluster 與回饋對象。

## 執行與交接

1. 內容編輯 AI 建立修改前語意基準：核心問題、各段主張、案例用途、結論、來源與 CTA 界線。
2. 內容編輯／SEO AI 逐項提出「改哪裡、SEO 理由、如何保持原意」，不先整篇重寫。
3. SEO／發布維護 AI 檢查意圖、metadata、H 標題、FAQ、內部連結、canonical、robots、OG、structured data 與關鍵字互搶。
4. 品牌素材 AI 對照首頁、文章列表與相關系列，記錄圖片是否足以支持內容與品牌風格；可重用既有核准素材時優先重用。
5. 若缺少合適素材，品牌素材 AI 建立插畫 brief，插畫設計 AI 產出候選，前端維護 AI 放入本地頁面。
6. 品質檢查 AI 逐段對照修改前後語意，並執行核心頁、視覺風格、插畫題意、手機／桌面、連結、sitemap 與草稿隔離回歸。
7. 不通過項目退回原負責角色；修正後重新驗收。
8. 總管向使用者提供 diff、語意對照、來源、本地預覽與發布後觀察指標。
9. 使用者核准後才可進入發布前檢查與發布。

## 驗收

- 每個改動都能對應需求單與 SEO 理由。
- 原文核心意義、案例、結論、來源及服務界線完全保持。
- 關鍵字自然，沒有堆砌或標題黨。
- 即時背景仍有效且有一手來源。
- 無明顯關鍵字互搶；metadata 與可見內容一致。
- 完整 `pre-publish-check.md` 與使用者預覽通過。

## 發布後觀察

- 發布後交由 `search-performance-feedback.md` 執行索引台帳與成效報告。
- Search Console 優先比較 28 天與前 28 天的曝光、點擊、CTR 與 query mix。
- 平均排名只看趨勢，不以單次手動搜尋判定成敗。
- 7／28／90 天依樣本量記錄，不因短期低樣本立即反覆改文。
- 實際 query 與目標詞需判定 `hit`、`partial_hit`、`miss` 或 `insufficient_data`，再回饋內容編輯與趨勢團隊。

## 完成與停止條件

- 完成：使用者核准、發布與正式站驗證完成，交接記錄可追溯。
- 停止：語意保真失敗、趨勢失效、證據不足、專業風險未解決或修改需要超出需求單。
